初期設定

GitHubのアクセストークンを取得してください。
  1. GitHubにログイン → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. 「Generate new token」を押す
  3. Repository access で haruYT03/blog だけを選択
  4. Permissions → Contents を Read and write に設定
  5. 生成されたトークンをコピーして下に貼り付ける
